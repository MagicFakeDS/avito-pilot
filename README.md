# AvitoPilot — ИИ-помощник продавца на Авито

Telegram-бот и сайт на базе **Claude**: присылаете ссылку на поиск Авито (или
вставляете скопированную выдачу) — бот собирает объявления конкурентов, считает
цены и продвижение по позициям и даёт практичный разбор рынка. Плюс: написать
объявление, подобрать цену, проверить объявление, ответить покупателю, замеры по
расписанию, выгрузка в Excel/CSV. Кроме Авито умеет Ozon, Wildberries и Яндекс.Маркет.

> Node.js 20+ · Claude API (`@anthropic-ai/sdk`) · Telegram (`grammy`) · Playwright (опц.)

## Что умеет

- **Анализ рынка.** Цены, продавцы, доля продвижения по позициям → сводка, советы, CSV.
- **По ссылке.** Бот сам открывает поиск Авито в браузере и собирает выдачу
  (читает только публичные данные, ничего не нажимает).
- **Тексты.** Заголовок и описание объявления по вашему товару.
- **Цена.** Три стратегии по собранной выдаче.
- **Проверка объявления** и **готовый ответ покупателю.**
- **Замеры по расписанию** — «каждый вечер в 21:00 собирай статистику по диванам в Москве».
- **Задачи** — каждая задача это отдельная сессия: бот помнит разговор и понимает
  уточнения («а в Казани?», «почему у лидеров дороже?»).

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите **токен**.
2. Получите **ключ Claude API** в [Anthropic Console](https://console.anthropic.com/).
3. Установите и запустите:

```bash
git clone https://github.com/MagicFakeDS/avito-pilot.git
cd avito-pilot
npm install
cp .env.example .env     # впишите BOT_TOKEN и ANTHROPIC_API_KEY
npm start
```

Бот и сайт работают в одном процессе. Без `BOT_TOKEN` поднимется только сайт.

> ⚠️ Пока не задан `BOT_ALLOWED_USERS`, ботом может пользоваться любой, кто его
> найдёт, — и тратить ваши токены Claude. Для личного использования впишите туда
> свой Telegram-id.

## Настройки (`.env`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | токен Telegram-бота |
| `ANTHROPIC_API_KEY` | — | ключ Claude API |
| `ANTHROPIC_WORKSPACE_ID` | — | ID рабочего пространства, если ключ к нему не привязан |
| `BOT_ALLOWED_USERS` | все | id пользователей через запятую, кому можно пользоваться ботом |
| `BOT_REQUEST_LIMIT` | 0 | лимит запросов на пользователя (0 = без лимита) |
| `BOT_ADMINS` | — | id админов через запятую — у них безлимит |
| `CLAUDE_MODEL` | `claude-opus-5-5` | модель Claude |
| `AVITO_PAGES` | `1` | сколько страниц выдачи загружать по ссылке (1–10) |
| `AVITO_HEADLESS` | `1` | `0` — показывать окно браузера (помогает пройти проверку Авито) |
| `PORT` / `HOST` | `3000` / `127.0.0.1` | где слушает сайт |
| `DB_FILE` | `data/db.json` | файл с данными |

## Нейросеть (Claude или ChatGPT)

По умолчанию используется **Claude** (`@anthropic-ai/sdk`). Можно переключить на
любой **OpenAI-совместимый** провайдер — ChatGPT, а также OpenRouter, DeepSeek,
Groq, локальные модели и т.п. — через `.env`:

```bash
AI_PROVIDER=openai
OPENAI_API_KEY=sk-...
# OPENAI_BASE_URL=https://api.openai.com/v1   # OpenRouter: https://openrouter.ai/api/v1
# OPENAI_MODEL=gpt-4o
# OPENAI_FAST_MODEL=gpt-4o-mini
```

Весь анализ, тексты, structured-JSON, работа с картинками и агент-режим работают
через единый слой (`src/claude.js`), так что провайдер меняется одной переменной.

## Загрузка по ссылке (опционально)

У Авито сильная защита от ботов. Чтобы заходы были стабильными:

1. Поставьте Playwright: `npm i playwright` (при необходимости `npx playwright install chromium`).
2. Один раз «прогрейте» профиль — пройдите проверку сами:
   ```bash
   npm run avito:login
   ```
   Откроется окно браузера с Авито; если появится проверка — пройдите её. Сессия
   сохранится в `browser-profile/`, дальше бот грузит выдачу сам. Капчу бот не
   обходит и автоматизацию не маскирует — надёжность даёт прогретый профиль.

В любой момент выдачу можно прислать вручную: ссылку или скопированную страницу
поиска (Ctrl+A, Ctrl+C) прямо в чат.

## Как пользоваться

Команд нет — просто пишите словами, что узнать и где:

- «Сколько стоят диваны в Москве и кто лидеры» → бот поймёт город и запрос,
  соберёт выдачу и ответит. Под ответом — кнопки «CSV», «Таблица», «Ещё страницы».
- «Напиши объявление на шкаф-купе 2 метра», «подбери цену на…», «проверь
  объявление…», «ответь покупателю: …» → ИИ распознаёт намерение и делает нужное.

Работа идёт через задачи: «Новая задача» → пишете запросы → «Мои задачи» для
переключения. Каждая задача помнит свой рынок и весь разговор.

## Как устроено

- **Разбор выдачи — три слоя** (чтобы смена вёрстки Авито не ломала сбор): разметка
  (`src/extract-dom.js`) → данные состояния страницы (`src/extract-state.js`) →
  резервно Claude читает текст (`src/extract.js`). Цифры (цены, медианы, доли
  продвижения) считает код, не нейросеть (`src/analytics.js`).
- `src/agent.js` — «мозг»: по свободному запросу определяет намерение, город и
  поисковый запрос (structured outputs).
- `src/bot.js` — бот на grammY: свободный ввод, очередь задач, Rich-сообщения с
  таблицами. `src/tools.js` — тексты/цена/проверка/ответ. `src/ai.js` — выводы по рынку.
- `src/fetch-avito.js` — загрузка в настоящем браузере (Playwright). `src/fetch-ozon.js`,
  `src/fetch-wb.js`, `src/markets.js` — другие площадки.
- `src/server.js`, `src/render.js` — сайт с теми же разборами и графиками.
  `src/store.js` — данные в JSON.

## Стоимость

Одна страница выдачи (50 объявлений) — примерно 12 тыс. входных и 6–8 тыс.
выходных токенов Claude. Актуальные цены — на странице тарифов Anthropic.
